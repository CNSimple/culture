# 燕赵遗韵 · Flask 交互原型

依据 `燕赵遗韵-项目执行方案书.md` 的七个核心界面与所给参考图制作。页面包含文化地图、成语档案、知识图谱、AI 问答、图片识别、研学助手和沉浸剧情入口。地图和关系节点可点击，页面之间可完整走通。

## 启动

需安装 Python 3.10 或更新版本：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000 。如果 `py` 不可用，先安装 Python，再用 `python -m venv .venv`。

也可以直接在浏览器中打开 `templates/index.html` 预览页面。直接打开时使用内置示例数据；通过 Flask 启动时使用 `app.py` 提供的接口。

## 原型边界

- 问答接口使用预置成语资料返回演示回答，附有资料名称；未接入大模型或 RAG。
- 图片识别展示用户选择的演示场景，未运行图像模型，因此不显示虚构的置信度。
- 剧情是可交互的二维场景；浏览器语音合成可播放对白，未接入 3D 引擎。
- 成语资料为简化的教学演示数据，正式发布前应由史料专家核对出处、年代、遗址对应关系。
